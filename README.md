# SleepyTigerTales

Scripts and channel analysis for the SleepyTigerTales YouTube channel — slow,
beautiful, gently melancholic bedtime stories for children, drawn from Korean
folktales and narrated for the parent-and-child bedtime routine.

## Contents

- `analysis/` — scene-by-scene hook & retention analyses of published videos.
  - [`hook-analysis-tiger-and-gotgam.md`](analysis/hook-analysis-tiger-and-gotgam.md) —
    why "The Tiger and the Got-gam" underperformed, and the script rules derived
    from it.
- `scripts/` — full production scripts (narration + visual directions + continuity
  sheets).
  - [`the-sun-and-the-moon.md`](scripts/the-sun-and-the-moon.md) — 해와 달이 된
    오누이, *The Children Who Became the Sun and the Moon*.

## Channel script rules (short version)

1. Hook — a question and a promise — in the first 15 seconds.
2. Story engine running before 0:45.
3. No CTAs inside the story; engagement lives in the description and pinned comment.
4. Pacing decelerates: the child should fall asleep before the video ends.
5. One continuity sheet per video; every generation prompt restates it.
6. Folk-tale refrains are repeated and slowed — repetition is the lullaby.
